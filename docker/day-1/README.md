# Docker-окружение для Вебинара (День 1: Вайб-кодинг против Скилов)

Изолированное окружение для честного сравнения работы агентов в двух режимах с сохранением результатов на Mac хосте.

## Сборка образа (если собирается заново)
Из корня репозитория:
```bash
docker build -t pytex-webinar:latest -f docker/day-1/Dockerfile .
```

## Быстрый запуск

### Режим 1: Чистый вайб-кодинг (без скилов и канона)
```bash
./docker/day-1/run-no-skills.sh
```
Внутри контейнера:
```bash
opencode
```
Промпт:
```text
Создай ручку POST /api/v1/links для сокращения ссылок и напиши к ней тест.
```

---

### Режим 2: Инженерный харнес (со скилами)
```bash
./docker/day-1/run-with-skills.sh
```
Внутри контейнера:
```bash
opencode
```
Промпт:
```text
Используй скил feature. Создай ручку POST /api/v1/links для сокращения ссылок.
```
