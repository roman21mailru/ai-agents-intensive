# Python-AI: интенсив «От вайб-кодинга к профессиональной AI-разработке»

> **Вы на ветке `main` (она же `day-1`).** Скилов и обвязки Дней 2-3 на этой ветке нет: они появляются на ветках `day-2` и `day-3`.

Учебный репозиторий трёхдневного интенсива Pytex. Сквозная тема — сервис коротких ссылок
на FastAPI. **Рабочий проект всегда лежит в `fastapi/`**, а день выбирается веткой.

**Приложение едино для трёх дней и доступно с первого дня** (монолит `linksvc` с доменами links,
analytics и billing). Побайтово одинаковы во всех трёх днях шесть объектов приложения и окружения:
`app/`, `alembic/`, `alembic.ini`, `uv.lock`, `docker-compose.yml`, `.env.example`.
`pyproject.toml` един по зависимостям и настройкам инструментов и отличается только учебным порогом
покрытия `fail_under`: `50` в Дне 1 (лестница `50 → 60 → 80 → 85`) и `85` в Днях 2-3.
Каталог `tests/` (вместе с `agent-battle/`) даёт общую базу из 98 тестов приложения во всех трёх днях;
в Дне 3 к ней добавлены два файла тестов обвязки — `tests/unit/test_kb_sync.py` (со `snap-1`) и
`tests/unit/test_layer_linter_exhaustive.py` (со `snap-4`), всего 104 теста.

От дня к дню **поэтапно наращиваются агентные скилы (7 → 9 → 15)** и инструменты оркестрации и
верификации (`.agents/skills/`, `.ai-team/`, `scripts/`, `tools/`, `.planning/`).

## Как переключаться между днями

Каталог один — `fastapi/`; меняется ветка:

```bash
cd ~/work/Python-AI
git checkout day-1      # День 1 (то же, что main)
git checkout day-2      # День 2
git checkout day-3      # День 3; контрольные срезы: git checkout snap-0 … snap-6
cd fastapi
uv sync
```

Каталогов с именами `day-1`, `day-2`, `day-3` в репозитории нет, поэтому `git checkout <ветка>`
работает без конфликта имён. После переключения выполните `uv sync` в `fastapi/`: зависимости во всех днях
одинаковы (общий `uv.lock`), но команда безопасна и приводит окружение в порядок.
Если у вас есть локальный `fastapi/.env`, который git не отслеживает (`ПРЕРЕКВИЗИТЫ.md`,
раздел 2.3), `git checkout day-1` может отказаться его перезаписывать: сохраните копию файла
и верните её после переключения.
