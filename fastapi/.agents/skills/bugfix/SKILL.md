# Skill: Bugfix

## Алгоритм исправления бага

> Если корневая причина не очевидна — переключи AI-IDE в **Plan mode** и
> разведай контекст до того как писать regression test. Не угадывай место
> правки. Если разведка показала что симптом и реальная причина в разных
> местах — это нормально, пометь и продолжай.

### 1. Подготовка
- Воспроизвести проблему — понять что именно сломано.
- Создать ветку: `git checkout -b bugfix/<JIRA-KEY>-<short-description>`.

### 2. Определить точку дефекта
- Найти файл и строку где возникает ошибка.
- Понять корневую причину, а не симптом.
- Если что-то существенное выяснилось по ходу (корневая причина не там
  где ожидал, скоуп шире чем казалось) — скажи об этом оператору перед
  тем как продолжать. Не молчи.

### 3. Сначала тест
- Написать regression test, который **падает** до фикса.
- Убедиться что тест действительно воспроизводит баг: `uv run pytest -q` — должен быть FAIL.

### 4. Минимальный фикс
- Исправить только корневую причину — не рефакторить попутно.
- Не менять публичный API если это не требуется для фикса.

### 5. Проверка
- `uv run pytest -q` — regression test теперь зелёный.
- `uv run ruff format .` — автоформатирование.
- `uv run ruff check --fix .` — автофикс автофиксимых правил (`I001`, `F401` и др.).
- `uv run ruff check .` — должно быть зелёно.
- `uv run basedpyright`
- `uv run pre-commit run --all-files` — прогнать все хуки перед коммитом. Если хук упал — исправить и перезапустить.
- **Зелёный тулчейн ≠ баг исправлен.** Для операций с тихим отказом (извлечение/парсинг/скрейпинг/трансформация) проверь результат на реальном входе, который воспроизводил баг, и сравни с эталоном — а не «непусто/без ошибки». См. `.agents/agents/testing.md`, «Зелёный прогон ≠ корректно».

Если что-то упало нетривиально (basedpyright ругается на код, который ты
не трогал; тест падает по неочевидной причине) — действуй по
`.agents/agents/error-handling.md`, не лепи `# type: ignore` без понимания.

### 6. Коммит
- `[agent] fix(<scope>): <описание бага на русском>` — один коммит. Тэг и
  scope английские, описание — русское (см. таблицу «Язык общения» в
  `.agents/AGENTS.md`).

### 7. В конце задачи
Коротко: «Bug `PROJ-XXX` исправлен, regression test добавлен, всё зелёное.
MR делать или есть правки?». Дальше — по ответу оператора.
