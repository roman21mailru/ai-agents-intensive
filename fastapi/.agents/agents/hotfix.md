# Hotfix rules

1. Сначала минимизировать scope изменения.
2. Использовать отдельную Jira-ветку в формате `hotfix/<JIRA-KEY>-<short-description>`.
3. Обязательно добавить regression test.
4. Не делать лишний рефакторинг внутри hotfix.
5. Зафиксировать что именно было исправлено и как откатить изменение.

## Дополнительно

- Менять только то, что нужно для исправления инцидента.
- Не смешивать hotfix с unrelated cleanup.
- После фикса обязательно проверить что баг не повторяется.
