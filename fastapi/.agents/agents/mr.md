# Merge request rules

MR должен быть понятным, коротким и проверяемым.

- В MR должно быть ясно, что именно изменилось.
- Нужно кратко объяснить зачем сделано изменение.
- Нужно перечислить какие тесты были запущены.
- Нужно указать возможные риски.
- Если изменение влияет на rollout — добавить rollout plan и rollback plan.
